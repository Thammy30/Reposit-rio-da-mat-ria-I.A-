# 🤖 Atividades da Matéria de IA

## 📚 Estudos em Python e Ciência de Dados

Este repositório contém os códigos e resoluções de exercícios práticos desenvolvidos na disciplina de Inteligência Artificial. Os exercícios abordam fundamentos de Python, lógica de programação, estatística e conceitos básicos de Ciência de Dados.

O objetivo é desenvolver o raciocínio lógico e compreender como os algoritmos funcionam na prática.

## 📁 Estrutura do Repositório

### 📖 Referências Teóricas

- **Estatística Prática para Cientistas de Dados:** conceitos de amostragem, distribuições, testes de significância e análise estatística.
- **Data Science do Zero:** referência para implementação de algoritmos e compreensão dos conceitos de Ciência de Dados.
- **Python para Análise de Dados:** manipulação de dados utilizando Pandas, NumPy e visualização com Matplotlib.
- **Mãos à Obra: Aprendizado de Máquina:** referência para conceitos de Machine Learning.
- **Apresentações de NumPy e Pandas:** materiais de apoio utilizados nas aulas.

### 💻 Exercícios Práticos

- **Lista.pdf:** documento contendo os desafios de programação propostos na disciplina.
- **Resoluções:** códigos desenvolvidos em Python para solucionar os exercícios.

## 📝 Conteúdos Abordados

Os exercícios foram organizados nos seguintes temas:
- **Fundamentos e Aritmética:** entrada e saída de dados e operações matemáticas.
- **Controle de Fluxo:** utilização de `if`, `for` e `while`.
- **Estruturas de Dados:** listas, dicionários e conjuntos.
- **Manipulação de Dados:** tratamento de textos, remoção de duplicatas e organização de informações.
- **Estatística Computacional:** cálculo de média, mediana, variância e desvio padrão.
- **Algoritmos:** busca, ordenação, Fibonacci, números primos e outros exercícios.
- **Criptografia:** implementação da Cifra de César.
- **Simulações e Aleatoriedade:** utilização do módulo `random` para geração de valores e simulações.
- **Visualização de Dados:** criação de gráficos utilizando Matplotlib.

## 🛠️ Metodologia

A abordagem utilizada busca priorizar a compreensão da lógica de programação e dos conceitos estudados.

### 🔹 Implementação dos Algoritmos
Alguns exercícios foram desenvolvidos manualmente, sem depender de funções prontas, para facilitar a compreensão de como os algoritmos funcionam.

### 🔹 Organização do Código
Utilização de funções, estruturas de repetição, condicionais e estruturas de dados para desenvolver códigos organizados e reutilizáveis.

### 🔹 Aplicação de Bibliotecas
Após compreender os conceitos básicos, algumas atividades utilizam bibliotecas como **NumPy, Pandas e Matplotlib** para trabalhar com dados e visualizações.

## 🎯 Objetivo
Desenvolver conhecimentos em Python e aplicar conceitos de programação, estatística e Ciência de Dados como base para o estudo de Inteligência Artificial.
